## 二、今天最重要的产出：模块边界与十条耦合

**这部分已写进 [`architecture.md`](../agents/architecture.md)，是本日最有价值的结论，不在此重复。**要点：

- **边界切在「看得见 / 判得对 / 控得住」上**，判据是**排查时分得清哪一层错**。感知不含策略——否则一次漏报分不清是「没看见」还是「看见了被否决」，而那正是排查的第一分叉。
- **十条模块间耦合约束**（速度↔转向权限、重合判定不能用里程、弯角不能靠巡线律、判决阈值由评分决定、黑带与标记同色、标记会遮挡灯带、像素阈值←标定←相机、上报↔播报共用一个事件、硬终止独立于状态机、确认帧数↔速度上限）。**这些是今天最容易被当成「两个独立模块」而踩掉的东西。**

参考项目恰好把感知/决策/控制揉在同一个 `while 1` 里、状态用 23 元组传递——它的 17 条缺陷里**超过一半是「边界没切」的直接后果**。

## 三、今天从实测里逼出来的结论（不是想出来的）

按「不测量就发现不了」排序：

1. **`e_theta` 是灯带相对车体的量**，所以内环误差是 `e_theta + e_theta_d`，不是看起来更自然的差。写成差会让航向环成为**正反馈**（车头偏右反而被命令继续右转）。潜伏了两轮，因为原有的符号测试用「灯带平行 + 横向偏置」，那里 `e_theta ≡ 0`，两种写法数值相同。改对后全程横向误差 48–73px → 1.4–12px。
2. **黑帽响应不是「暗像素检测器」**——它在**亮结构的边缘**也响应。用它当黑带判据时，弯角处灯带自己的亮边被当成一条 162px 宽的终点黑带，车体在弯角提前结束。
3. **池壁之外的暗区**也会被当成黑带，而且是两种不同的路径：整片暗区（跨度大）、以及被画面边缘裁成几像素的暗条（跨度小但贴边）。于是黑带判据需要三条物理约束：**必须是几像素厚的带 + 必须在画面内部 + 必须灯带可见**。
4. **标记会遮挡灯带，被截断的游程其中心偏向存活一侧**，直接把中心线拉偏（表现是 `e_y` 恒定 −9.4px 偏置）。所以分割的闭运算核必须**大于标记直径**——正确性要求。
5. **弯角三点**：判据用 `confidence` 下降为主（实测逼近直角时单调 0.93→0.49，而 `curvature` 只在最后 50mm 抬头）；弯角推进**必须独立于状态**（灯带在弯中途必然消失）；弯角结束后**需要不应期**（否则立刻识别出第二个弯再转 90°）。
6. **`cv2.circle` 是赋值不是叠加**——我按「水面高光」的意图画，结果盖了一批**暗圆盘**，正好是漏油点的特征。
7. **同一个合成场地揭示了分割阈值的真实余量**：水下衰减把灯带饱和度抬到 ~80 而池底只有 ~125，绝对阈值余量很薄。改用 top-hat（比较像素与自身邻域）后覆盖率 40 行 → 140 行。

## 四、今天写的代码 —— **以及它靠不住的地方**

### 写了什么

`src/`（感知 / 控制 / 状态机 / 上报 / 平台 / 占位动力学 / 运行装配）、`tests/`（90 个测试，1 个是 `@expectedFailure`）。各目录职责见 [`AGENTS.md`](../../AGENTS.md) 的「仓库结构」表。

### 它证明了什么

- **整条链路可以在没有硬件时跑通**：`platform` 有记录型回退，所以「相机 → 偏差 → 判决 → 上报 → MAVLink 帧」这条链在开发机上端到端可执行。
- **边界切得对**：90 个测试里绝大多数是单元级的（喂手造观测），说明决策逻辑确实独立于感知与动力学。
- **坑是固化的而不是被记住的**：每个实测发现都留了针对性测试（符号、黑带三条约束、遮挡致偏、弯角不应期、触壁按次计数）。

### 它靠不住的地方（**用户提醒，我同意并在此写明**）

**这份实现是「一份参考实现」，用来把约束和坑固化下来，未必适配本项目，后面很可能大改。**具体靠不住的点：

| 靠不住的地方 | 为什么 |
| --- | --- |
| `plant.py` 的**全部动力学参数** | 占位值，文件头已写明。**提交转角长度与弯角增益都建立在它们之上**——对着它们调参等于拟合虚构，所以我没有继续调 |
| `ChannelMap` 的默认值 | 抄参考项目的 ArduSub 布局。鱼有几个通道、是不是这套布局**未确认**（backlog `#4`） |
| 全部**像素阈值** | 由 `Calibration` 的默认相机（高度 0.20m、HFOV 90°）推出。真实相机的型号/高度/视场未确认（backlog `#4`） |
| 灯带分割方法默认 `tophat` | 因为灯带颜色未确认而选了最抗色偏的一种，**并非因为实测过真实灯带** |
| `MarkerParams.discriminator = "none"` | 误识别点外观不知道（backlog `#1`）。判别规则做成了可插拔配置，但特征本身未知 |
| 弯向 `corner_turn_sign` | 取自赛题图的箭头。若实际是左转，默认值会让车直接开向池壁 |
| `arena.py` 的合成场地 | 池底平面 + 严格正下视的仿射模型；**没有透视、没有折射、没有焦散**；水只建模成逐通道增益 + 辉光。它能验证「结构对不对」，不能验证「阈值好不好」 |
| 弯角通过性 | 一种起始条件能跑完全程，另两种约 69% 后终止（backlog 弯角组） |

**重写时值得保留的不是这些代码，而是**：模块边界（architecture 第二节）、十条耦合约束（第三节）、以及上面第三节的七个坑。代码本身可以整体替换，这三样换掉就要重新踩一遍。
